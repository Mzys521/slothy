# Slothy 0.1.4.2-beta

English first, followed by 中文. This is the first merged release from the `explore` line.

## English

### Updates in this version

- **Large attachments**: files up to **32 MiB each** and **128 MiB per conversation** are
  accepted. Uploads are received first; the model receives a bounded 60,000-character
  preview and `read_uploaded_file` reads 8,000-character pages directly from SQLite, so the
  full file is never injected into the prompt.
- **Checkpoint recovery**: interrupted runs continue from LangGraph's saved SQLite
  checkpoint instead of deleting state and rebuilding from chat history. Recovery keeps the
  original run, model, attachments and completed tool tasks, including after a restart;
  streaming resume uses the correct query parameter and lost acknowledgements reconcile
  without silently resending the request.
- **Irreversible-action review**: deletion now has a distinct Delete label across approval
  and activity histories. Irreversible actions use a red high-risk panel with explicit
  badges and a red approval button; ordinary writes keep their existing style.
- **Context and observability foundation**: deterministic prompt sections, checkpointed
  runtime request snapshots, model-call JSONL records, Work Details context bars, decision
  model configuration, opt-in model catalog and the official DeepSeek Search tool remain
  included from the `explore` line.

## 中文

### 本次更新

- **大附件**：单文件最大 **32 MiB**、单会话最大 **128 MiB**。文件先完整接收；模型只接收
  60,000 字符的有界预览，`read_uploaded_file` 直接从 SQLite 按 8,000 字符分页读取，不会把
  完整文件注入提示词。
- **检查点恢复**：中断的运行从 LangGraph 已保存的 SQLite 检查点继续，而不是删除状态后
  从聊天历史重建。恢复会保留原始运行、模型、附件及已完成的工具任务，应用重启后同样有效；
  流式恢复使用正确的查询参数，丢失的完成确认会进行对账，不会静默重发请求。
- **不可逆操作审核**：删除在审批与活动历史中使用独立的 Delete 标记；不可逆操作使用红色
  高风险面板、明确徽章和红色批准按钮；普通写入保持原有样式。
- **上下文与可观测性基础**：确定性提示词分节、检查点运行时请求快照、模型调用 JSONL、
  工作详情上下文条形图、决策模型配置、手动模型目录与 DeepSeek 官方搜索工具均随
  `explore` 分支合入。

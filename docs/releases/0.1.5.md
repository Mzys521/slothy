# Slothy 0.1.5

[简体中文](#简体中文) · [English](#english) · 2026-11-22

## 简体中文

Slothy 0.1.5 是 Windows x64 正式版。本版完善了已有数据库的启动保护，以及运行中断后的恢复。

### 从 0.1.4.2 Beta 升级

1. 退出 Slothy，备份 `%APPDATA%\slothy\data` 后运行安装包。
2. 安装 0.1.5。已有数据库结构兼容时可直接打开，缺少版本标记时会在核验后补建。
3. 出现恢复提示时，对符合条件的旧库选择**继续使用原目录**。应用会先验证备份，再执行升级。
   选择**备份后重新开始**时，会先验证备份，再初始化空库。

### 本次更新

- **运行恢复。** 每次提交使用稳定的请求 ID，恢复时校验运行与检查点。缺少模型服务商时，
  仍可读取历史和待审批记录。
- **附件与产物。** 聊天和历史通过元数据校验附件，上传中断后可复用上传 ID。
  会话移动或分叉后，产物链接仍通过生成时的目录定位。
- **可恢复清理。** 清空消息、删除会话或工作区可在重启后继续。清理时一并处理会话诊断日志。
- **上下文与工具。** 模型请求按配置的上下文窗口控制大小。失效引用会被标记，并从后续请求移除。
  决策计划在执行模式下可收窄工具和上下文，现有审批规则继续生效。
- **记忆与诊断。** 记忆设置分别显示已保存和已生效版本。诊断日志写入失败时，已生成的回答仍可返回。

### 安装产物

构建产物位于 `web/release/slothy/0.1.5/`。

| 文件 | 用途 |
| --- | --- |
| `slothy-0.1.5-x64-Setup.exe` | Windows x64 NSIS 安装程序 |
| `slothy-0.1.5-x64-Setup.exe.blockmap` | 差分更新映射 |
| `SHA256SUMS-0.1.5.txt` | 安装包与差分映射的 SHA-256 校验值 |

应用版本为 `0.1.5`，Windows 文件版本为 `0.1.5.0`。安装包未签名。

- TypeScript 类型检查和 Ruff 通过。

## English

Slothy 0.1.5 is a stable release for Windows x64. It makes startup safer for
existing databases and improves recovery when a run is interrupted.

### Upgrade from 0.1.4.2 Beta

1. Close Slothy and back up `%APPDATA%\slothy\data` before running the installer.
2. Install 0.1.5. Compatible databases open directly, even when the version
   marker needs to be recreated.
3. If prompted, choose **继续使用原目录 (Keep existing data)** for eligible legacy
   databases. Slothy verifies a backup before applying the upgrade. The
   **备份后重新开始 (Back up and start fresh)** option creates empty databases after
   verifying the backup.

### Changes

- **Run recovery.** A submission has a stable request ID. Resume checks the
  expected run and checkpoint. History and pending approvals stay readable
  when no model provider is configured.
- **Attachments and artifacts.** Chat and history validate attachment metadata
  without loading entire files. Interrupted uploads can reuse their IDs.
  Artifact links use the original generation location across session moves
  and forks.
- **Durable cleanup.** Clearing messages or deleting a session or workspace
  can continue after a restart. Session diagnostics are cleaned up with the
  other session data.
- **Context and tools.** Model requests fit the configured context window.
  Missing references are marked and removed from the next model request.
  Enforced decision plans can narrow tools and context within the existing
  approval policy.
- **Memory and diagnostics.** Memory settings show saved and applied revisions
  separately. A diagnostics write failure does not discard a successful
  model reply.

### Installer

Build output is in `web/release/slothy/0.1.5/`.

| File | Purpose |
| --- | --- |
| `slothy-0.1.5-x64-Setup.exe` | NSIS installer for Windows x64 |
| `slothy-0.1.5-x64-Setup.exe.blockmap` | Differential update map |
| `SHA256SUMS-0.1.5.txt` | SHA-256 checksums for the installer and blockmap |

The app version is `0.1.5` and the Windows file version is `0.1.5.0`.
The installer is unsigned.

- TypeScript and Ruff passed.
- The renderer, frozen Python backend and NSIS installer were built.
  The production bundle audit passed and the two release files were hashed.
- Packaged-backend acceptance passed with a local test model, including

# Slothy 0.1.6

[简体中文](#简体中文) · [English](#english) · 2026-11-27

## 简体中文

Slothy 0.1.6 是 Windows x64 正式版。主要更新是可视化配置连接器，以及让文档、记忆关系和任务产物更容易查看。

### 本次更新

- **连接器。** 可通过表单创建和编辑 stdio、Streamable HTTP、SSE MCP 服务。确认后实际测试连接或刷新工具，详情可展开查看参数。Skills 支持 Markdown 预览和多文件管理，保存时生成 `SKILL.md`。保留原有 JSON 和 ZIP 导入。Agent 调用工具继续走审批流程。
- **文档读取。** 通过上传、`@` 引用或工作区读取提取 PDF、DOCX、PPTX 的文本。扫描 PDF 需要 OCR，旧版 `.doc` 和 `.ppt` 需转换为新版格式。
- **记忆图谱。** 节点常显名称，选中时加深标签。图谱显示已有的事实、概念与语义关系，也可手动建立连线。
- **上下文监控。** 四个视图改用卡片。工作详情以环形图展示本轮估算输入，可切换单次调用，Provider 实际用量单独展示。
- **任务产物。** 已完成的回复下方列出本轮成功写入或生成的文件。桌面端点击可打开原文件，历史与归档会话保留这些卡片。

### 安装与升级

关闭 Slothy，备份 `%APPDATA%\slothy\data` 后运行安装包。应用会先验证已有数据结构，兼容的数据库可直接打开。需要处理旧库时，恢复提示会显示可用的选项。

| 文件 | 用途 |
| --- | --- |
| `slothy-0.1.6-x64-Setup.exe` | Windows x64 NSIS 安装程序 |
| `slothy-0.1.6-x64-Setup.exe.blockmap` | 差分映射 |
| `SHA256SUMS-0.1.6.txt` | 安装程序和差分映射的 SHA-256 校验值 |

应用版本为 `0.1.6`，Windows 文件版本为 `0.1.6.0`。安装包未签名。

MCP 的「已连接」表示当前进程最近一次探测成功。重启后，已启用的连接会先显示「待验证」。Agent 可读取不超过 1 MiB 的 UTF-8 Skill 参考文件。

### 验证

568 项后端测试、103 项前端和桌面测试、TypeScript 类型检查及 Ruff 均通过。生产资源审计和 NSIS 完整性检查通过。通过安装包内的后端验证了实际 stdio 工具发现、Skill 重启恢复、PDF/DOCX/PPTX 文本提取及产物定位。

## English

Slothy 0.1.6 is a stable Windows x64 release. It adds visual connector setup and makes documents, memory relationships, and generated files easier to inspect.

### Changes

- **Connectors.** Create and edit stdio, Streamable HTTP, and SSE MCP servers through forms. Confirm a real connection test or tool refresh, then inspect tool parameters. Create Skills with a Markdown preview and multiple references. Slothy generates `SKILL.md` on save. Existing JSON and ZIP imports and Agent tool approvals are supported.
- **Document reading.** Extract PDF, DOCX, and PPTX text from uploads, `@` references, or workspace files. Scanned PDFs require OCR. Convert legacy `.doc` and `.ppt` files to their newer formats first.
- **Memory graph.** Node labels stay visible and gain emphasis when selected. The graph shows stored factual, concept-membership, and semantic links and supports manually adding connections.
- **Context monitor.** The four views use cards. Work Details shows estimated input as a donut chart for the turn or an individual call, with provider-reported usage in its own card.
- **Work artifacts.** Completed replies list files successfully written or generated during the turn. The desktop opens the original file. History and archived conversations retain the cards.

### Install or upgrade

Close Slothy, back up `%APPDATA%\slothy\data`, and run the installer. Slothy verifies the existing database layout at startup. Compatible databases open directly, and an eligible legacy store can be handled through the recovery prompt.

| File | Purpose |
| --- | --- |
| `slothy-0.1.6-x64-Setup.exe` | NSIS installer for Windows x64 |
| `slothy-0.1.6-x64-Setup.exe.blockmap` | Differential update map |
| `SHA256SUMS-0.1.6.txt` | SHA-256 checksums for the installer and blockmap |

The app version is `0.1.6` and the Windows file version is `0.1.6.0`. The installer is unsigned.

MCP connection status reflects the latest check in the current process. Enabled connections initially show **Not checked** after a restart. The Agent reads Skill references as UTF-8 text up to 1 MiB per file.

### Verification

All 568 backend tests, 103 renderer and desktop tests, TypeScript checks, and Ruff checks passed. The production audit and NSIS integrity check passed. The bundled backend verified real stdio tool discovery, Skill persistence across restart, PDF/DOCX/PPTX extraction, and locating an artifact's original file.
